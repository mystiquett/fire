# 坦克大战 · BATTLE CITY

> 在线试玩：<https://mystiquett.github.io/fire/>

一个无需构建、无第三方依赖的网页版坦克大战。使用原生 HTML / CSS / Canvas 2D 与 Web Audio 实现，打开 `index.html` 即可游玩。

## 运行

直接双击 `index.html`，或在目录中启动任意静态服务器：

```bash
python3 -m http.server 8123
# 打开 http://127.0.0.1:8123
```

## 操作

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | `WASD` / 方向键 | 左侧虚拟摇杆 |
| 开火 | `Space` / `J` / `K` | 右侧 `FIRE` |
| 暂停 | `P` / `Esc` | 顶部暂停按钮 |
| 静音 | `M` | 顶部音效按钮 |

## 内容

- 5 个手绘战区：绿野前哨、断桥水域、暗林迷阵、钢铁堡垒、极寒禁区。
- 4 种敌军坦克：轻型、高速、炮击、重甲；带寻路、瞄准、破墙与基地突袭逻辑。
- 3 档难度：新兵（5 命）、经典（3 命）、老兵（2 命），不同敌军数量、火力与得分倍率。
- 6 种战术道具：火力升级、能量护盾、额外生命、全屏轰炸、时间冻结、基地钢化。
- 砖墙可破坏、钢墙可被满级炮弹击穿；水面阻挡坦克，树林遮蔽视线，冰面产生滑行。
- 程序化像素画面、粒子爆炸、履带痕迹、屏幕震动、CRT 扫描线与 Web Audio 音效。
- 最高分保存在浏览器 `localStorage`。
- 响应式布局，桌面键盘与移动端触控均可游玩。

## 文件

```text
index.html      页面结构

js/data.js      地图、难度、敌军与道具配置

js/game.js      游戏循环、AI、碰撞、渲染
js/main.js      HUD、界面状态、输入与触控
```
